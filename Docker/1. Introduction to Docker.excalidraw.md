-> A Docker Image is a read-only template used to create Docker containers.
-> Contains application code, dependencies, libraries, runtime and configurations.
-> It is built using a Dockerfile.
-> Images are immutable (cannot be directly modified).
-> A single image can create multiple containers.
-> Images can be stored and shared through registries like Docker Hub. ^ollL5Tdu

-> A Docker Container is a running or stopped instance of a Docker Image.
-> It provides an isolated environment to execute an application.
-> Has its own filesystem, processes, network and configurations.
-> Containers are lightweight and portable.
-> Multiple containers can be created from the same image.
-> Containers can be started, stopped, restarted and deleted.
-> Changes made inside a container are stored in its writable layer and are lost
 when the container is deleted (unless persistent storage is used). ^jihUfxUh
