UDP - User Datagram Protocol ^rQeTRYaq

-> It is a Layer 4 (Transport Layer) Protocol
-> Data Unit is called Datagram.
-> We have a concept of PORTs to address processes in the host.
-> It's a stateless protocol.
-> Does not require connection establishment
(Unlike TCP's 3 way handshake)
-> Very simple protocol for communication.
-> Header size of UDP datagram is 8 bytes. 
-> As it is a stateless protocol, it is unreliable.
-> It just generates the Datagram and send it over internet. No checking or anything
-> Very Fast compared to TCP but is not reliable.
->Audio / Video Streaming Platform or Gaming Platform uses UDP. ^Smea6w0K

Use Cases for UDP:
-> WebRTC
-> Gameplay Traffic
->Video Streaming
->VPN
->DNS -> If DNS build on TCP it will take 11 Trips instead UDP takes 2 Trip 
Aslo DNS itself has a mechanism to detect package loss.
->QUIC -> takes Fast Property of UDP and implement reliablity from thier side.
