## How to View Drawings Directly on GitHub (Without Downloading)

Because these files are saved in `.excalidraw.md` format, GitHub's default viewer renders them as raw Markdown and JSON data. To view the visual diagrams directly in your browser:

### Recommended: Use a Browser Extension (Method 2)
Install a browser extension that automatically renders Excalidraw diagrams directly on GitHub pages:
- **[Github Excalidraw Renderer](https://chromewebstore.google.com/detail/github-excalidraw-rendere/fmmhffehpjndlkgocgcojhkpccffadbe)** (Available on Chrome Web Store for Chrome, Edge, Brave)
- Once installed, navigating to any `.excalidraw.md` file in this repository will display the rendered drawing inline just like an image.

### Quick Alternative: Press `.` on your keyboard (Web VS Code)
1. On any page of this repository, press the **`.` (period)** key on your keyboard (or change `github.com` to `github.dev` in your browser URL bar).
2. This opens the repository inside GitHub's free browser-based VS Code.
3. Install the **Excalidraw** extension from the Extensions tab (`Ctrl+Shift+X`).
4. Click any drawing to view and interact with it.
